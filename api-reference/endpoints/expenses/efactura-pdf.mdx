---
title: 'Download e-Factura PDF'
openapi: 'GET /expenses/{id}/efactura-pdf'
description: 'Stream the ANAF e-Factura PDF for an expense imported from the SPV inbox'
---

## Overview

Returns the e-Factura PDF for an expense that was imported from the ANAF
e-Factura SPV inbox. The PDF is rendered on demand via the ANAF public
validator the first time it is requested and cached on disk for subsequent
calls.

This endpoint requires the same Bearer authentication as the rest of the API.
Use the `efactura.pdf_url` field from [Retrieve Expense](/api-reference/endpoints/expenses/retrieve)
to discover the URL — it is only present when `efactura.xml_available` is
`true`.

## Path Parameters

<ParamField path="id" type="string" required>
  The CzUid of the expense
</ParamField>

## Response

Returns `application/pdf` binary content with `Content-Disposition: inline`.

## Error Responses

<ResponseField name="404 Not Found">
  Returned when the expense was not imported from SPV (`efactura_not_available`)
  or its XML file is missing on disk (`efactura_xml_missing`).
</ResponseField>

<ResponseField name="502 Bad Gateway">
  The ANAF validator failed to convert the XML to PDF (`efactura_pdf_generation_failed`).
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.contazen.ro/v1/expenses/exp_abc123/efactura-pdf" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -o efactura.pdf
```

```javascript JavaScript
const expenseId = 'exp_abc123';
const response = await fetch(`https://api.contazen.ro/v1/expenses/${expenseId}/efactura-pdf`, {
  headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
});

const blob = await response.blob();
```

```php PHP
$expenseId = 'exp_abc123';
$ch = curl_init("https://api.contazen.ro/v1/expenses/{$expenseId}/efactura-pdf");
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER     => ['Authorization: Bearer YOUR_API_KEY'],
]);
$pdf = curl_exec($ch);
curl_close($ch);
file_put_contents('efactura.pdf', $pdf);
```

</RequestExample>
